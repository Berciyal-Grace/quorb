# Quorb 0.5.0 — Instalar Codex desde Ajustes / Install Codex from Settings

## Español

Conectad Codex con menos pasos: Ajustes permite comprobar si el CLI está
disponible y, si falta, ofrece instalarlo con vuestra confirmación.

### Nuevo

- Instalación asistida y opcional de Codex desde Ajustes, con progreso y resultado.
  El diálogo explica los requisitos antes de ejecutar la instalación.
- Uso del paquete oficial `@openai/codex@0.162.1` en una carpeta propia de Quorb,
  sin instalación global ni cambios en el PATH del sistema.
- Comprobación del ejecutable y de su versión antes de aceptar la instalación;
  si falla, no se sustituye una instalación anterior.

### Mejorado

- Detección del CLI en el PATH y en ubicaciones conocidas, incluida la carpeta
  gestionada por Quorb. En Windows también se consultan las rutas del registro.
- El resultado de la instalación se conserva al navegar por Ajustes y se evita
  iniciar dos instalaciones a la vez.
- Guías ES/EN actualizadas para distinguir instalación, login y comprobación de
  conexión. Instalar el CLI no inicia el login ni guarda cambios pendientes.

### Importante e instalación

- Se requiere una instalación existente de Node.js 22 o superior con su npm
  asociado y arquitectura compatible. Quorb no instala Node.js/npm, no pide
  elevación y no instala automáticamente Claude o Gemini.
- La instalación asistida se limita a Windows x64/ARM64. Los instaladores de esta
  release siguen siendo Windows x64: no se anuncia un instalador ARM64.
- Las pruebas de código no sustituyen la validación funcional en Windows;
  la instalación real de Codex, el login y las credenciales siguen pendientes
  de confirmación del propietario.
- Cuando se publique 0.5.0, descargad el EXE o MSI desde su release. No se prometen
  actualizaciones automáticas desde el repositorio privado. La firma del updater
  no es Authenticode ni evita SmartScreen; no desactivéis las protecciones.
- Esta versión no incorpora una limpieza completa de datos y credenciales al
  desinstalar ni una revocación de sesiones OAuth.

## English

Connect Codex with fewer steps: Settings checks whether the CLI is available
and, when it is missing, offers to install it with your confirmation.

### New

- Optional assisted Codex installation from Settings, with progress and results.
  The confirmation dialog explains the requirements before installation starts.
- The official `@openai/codex@0.162.1` package is installed in a Quorb-owned folder,
  without a global installation or changes to the system PATH.
- The executable and its version are checked before accepting the installation;
  a failed attempt does not replace a previous installation.

### Improved

- CLI detection checks PATH and known locations, including Quorb's managed
  folder. On Windows it also checks registry paths.
- Installation results survive navigation within Settings, and duplicate
  simultaneous installations are prevented.
- Updated EN/ES guides distinguish installation, login and connection checks.
  Installing the CLI does not start login or save pending settings.

### Important and installation

- An existing Node.js 22 or newer installation with its paired npm and compatible
  architecture is required. Quorb does not install Node.js/npm, request
  elevation, or automatically install Claude or Gemini.
- Assisted installation is limited to Windows x64/ARM64. This release's installers
  remain Windows x64; an ARM64 application installer is not being announced.
- Source tests do not replace functional Windows validation. Actual Codex
  installation, login and credentials still await owner confirmation.
- Once 0.5.0 is published, download its EXE or MSI from the release. Automatic
  updates from the private repository are not promised. Updater signing is not
  Authenticode and does not prevent SmartScreen warnings; do not disable Windows
  protections.
- This version does not add complete uninstall cleanup of app data and credentials
  or OAuth session revocation.
