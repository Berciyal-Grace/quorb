# Quorb 0.2.0

Varias cuentas por proveedor (#33): añade cuentas adicionales de los nueve
proveedores, cada una con su nombre, su informe y su sesión, y tres regresiones
del propio cambio resueltas.

## Español

### Lo que notarás
- Cada proveedor admite varias cuentas a la vez (Claude, ChatGPT/Codex, Gemini,
  Cursor, GitHub Copilot, NaN Builders, OpenRouter, Anthropic API y OpenAI API).
- Pones nombre a cada cuenta adicional y se ve en la tira y en los informes
  («Claude · Trabajo»); cada una tiene su propio círculo, su resumen y su aviso.
- Las cuentas de Claude, Codex y Gemini usan su propia carpeta de sesión, así el
  «Iniciar sesión» no pisa la cuenta principal (`CLAUDE_CONFIG_DIR`,
  `CODEX_HOME` y `GEMINI_CLI_HOME`).
- Cada cuenta guarda sus claves por separado; al eliminarla se borran también
  sus claves del Administrador de credenciales.
- El widget ya no puede borrar cuentas: solo guarda sus propios ajustes (borde,
  monitor, orden y visibilidad) y nunca toca cuentas, atajos ni secretos.
- Guardar la clave de una cuenta antes de crearla ya no la deja en «Falta
  conectar»: al confirmar el guardado se releen los secretos.
- «Uso oficial» funciona también en cuentas adicionales (por ejemplo
  `openrouter:abc123` abre la página de OpenRouter).

### Importante
- Verificado en Linux: tests, comprobación de tipos dentro del build y
  `cargo test`. La validación en Windows **sigue pendiente**. En particular, no
  está probado de extremo a extremo el alta de cuentas en Windows: el
  Administrador de credenciales y el login por CLI (sobre todo `GEMINI_CLI_HOME`
  en Gemini) se han revisado y cubierto con lecturas y pruebas de wiring, pero
  no con una ejecución completa. No se reclama que funcione en Windows sin
  verificar.
- Teclado y lectores de pantalla: el foco de los modales y paneles laterales y
  los anuncios para lectores de pantalla siguen pendientes de ajustar y validar.
  Esta versión no reclama mejoras de accesibilidad.
- La desaparición ocasional del widget sigue en investigación y **no está
  corregida** en esta versión.
- Este instalador sigue sin firma Authenticode, así que Windows puede mostrar
  «Editor desconocido» o SmartScreen. La firma del updater (minisign) es
  distinta y no acredita al editor. No desactives las protecciones.
- El feed anónimo del updater sigue siendo privado e inaccesible (404 conocido).
  Mientras siga así, la actualización automática no funcionará: requiere un
  repositorio público o un canal de actualizaciones accesible. No se promete
  actualización automática.
- El repositorio es privado: descargar desde Releases exige una cuenta de GitHub
  con acceso. Nunca incrustes un token ni una clave personal.

### Instalar
1. Abre Releases en GitHub con una cuenta con acceso al repositorio.
2. Descarga el instalador `-setup.exe` (recomendado) o el `.msi`.
3. Cierra Quorb desde el menú de la bandeja con «Salir».
4. Haz una copia de `%APPDATA%\es.egdev.quorb` antes de sustituir la versión.
5. Instala y abre Quorb.

## English

### What you'll notice
- Each provider supports multiple accounts at once (Claude, ChatGPT/Codex,
  Gemini, Cursor, GitHub Copilot, NaN Builders, OpenRouter, Anthropic API and
  OpenAI API).
- You name each extra account and it shows in the strip and the reports
  ("Claude · Work"); every account has its own ring, summary and alert.
- Claude, Codex and Gemini accounts use their own session folder, so "Sign in"
  does not overwrite the main account (`CLAUDE_CONFIG_DIR`, `CODEX_HOME` and
  `GEMINI_CLI_HOME`).
- Each account stores its own keys separately; deleting it also clears its keys
  from Windows Credential Manager.
- The widget can no longer erase accounts: it only saves its own settings (dock
  edge, monitor, order and visibility) and never touches accounts, shortcuts or
  secrets.
- Saving an account's key before creating the account no longer leaves it stuck
  on "Not connected": secrets are re-read once the save is confirmed.
- "Official usage" now also works on extra accounts (for example
  `openrouter:abc123` opens the OpenRouter page).

### Important
- Verified on Linux: tests, type checking inside the build and `cargo test`.
  Windows validation **remains pending**. In particular, adding accounts on
  Windows has not been tested end to end: Credential Manager and CLI login
  (especially `GEMINI_CLI_HOME` for Gemini) have been reviewed and covered by
  code reading and wiring tests, but not by a full run. This version does not
  claim it works on Windows unverified.
- Keyboard and screen readers: focus in modals and side panels, and
  screen-reader announcements, still need adjustment and validation. This
  version does not claim an accessibility improvement.
- The occasional widget disappearance is still under investigation and is **not
  fixed** in this version.
- This installer still has no Authenticode signature, so Windows may show
  "Unknown publisher" or SmartScreen. The updater signature (minisign) is
  different and does not vouch for the publisher. Do not disable protections.
- The anonymous updater feed is still private and inaccessible (known 404).
  While it stays that way, automatic updates will not work: it needs a public
  repository or an accessible update feed. No automatic updates are promised.
- The repository is private: downloading from Releases requires a signed-in
  GitHub account with access. Never embed a token or a personal key.

### Install
1. Open Releases on GitHub with an account that has access to the repository.
2. Download the `-setup.exe` installer (recommended) or the `.msi`.
3. Close Quorb from the tray menu using "Exit" («Salir»).
4. Back up `%APPDATA%\es.egdev.quorb` before replacing the current version.
5. Install and open Quorb.
