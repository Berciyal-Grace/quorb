# Quorb 0.1.2

Siguiente versión estable. Reúne el aviso de actualización disponible ya
fusionado y mantiene las protecciones que ya venían de la 0.1.1.

## Español

### Lo que notarás
- Cuando la tira detecta una actualización disponible, ahora lo comparte con
  Ajustes: la sección «Versión instalada» muestra la versión nueva sin que
  tengas que pulsar «Buscar ahora». Ocurre con las comprobaciones automáticas
  activadas y el endpoint accesible.
- Si hay actualización, se muestra la versión y decides instalarla; nada se
  descarga ni se instala por su cuenta.
- Se mantienen dos protecciones que ya venían de la 0.1.1: Ajustes no pierde
  ediciones mientras el guardado está en curso, y el arranque de la tira
  conserva reintentos y estados «Cargando…»/«Reintentar». No cambian aquí.

### Importante
- Verificado en Linux (tests, typecheck y `cargo test`). La validación visual,
  del updater y del instalador en Windows sigue **pendiente**.
- Este instalador todavía no tiene firma Authenticode, así que Windows puede
  mostrar «Editor desconocido» o un aviso de SmartScreen. La firma del updater
  (minisign) es distinta y no acredita al editor. Estamos evaluando cómo
  firmarlo (#20); el uso de SignPath no está garantizado ni aceptado.
- No desactives las protecciones de SmartScreen para saltarte el aviso.
- Descarga solo las releases oficiales del repositorio y verifica su origen.
- El repositorio es privado: descargar desde Releases exige una cuenta de GitHub
  con acceso. La accesibilidad pública del endpoint del updater (`latest.json`)
  no está verificada y aún no es público; nunca incrustes un token personal.
- La conservación de ajustes durante la instalación nativa sigue pendiente de
  comprobar en Windows.
- Aplicar «Arrancar con Windows» mediante el guardado manual de Ajustes
  sigue pendiente (#19) y queda fuera de esta versión.

### Instalar
1. Abre Releases en GitHub con una cuenta con acceso al repositorio.
2. Descarga el instalador `-setup.exe` (recomendado) o el `.msi`.
3. Cierra Quorb desde el menú de la bandeja con «Salir».
4. Haz una copia de `%APPDATA%\es.egdev.quorb` antes de sustituir la versión.
5. Instala y abre Quorb.

## English

### What you'll notice
- When the strip detects an available update, it now shares it with Settings:
  the «Installed version» section shows the new version without you pressing
  "Check now". This happens with automatic checks enabled and the endpoint
  reachable.
- If an update exists, its version is shown and you choose to install it;
  nothing is downloaded or installed on its own.
- Two protections from 0.1.1 remain: Settings does not drop edits while saving
  is in flight, and strip startup keeps its retries and "Loading…"/"Retry"
  states. Neither changes here.

### Important
- Verified on Linux (tests, typecheck and `cargo test`). Windows visual, updater
  and installer validation remain **pending**.
- This installer still has no Authenticode signature, so Windows may show
  "Unknown publisher" or a SmartScreen warning. The updater signature (minisign)
  is different and does not vouch for the publisher. We are evaluating how to
  sign it (#20); using SignPath is not guaranteed or accepted.
- Do not disable SmartScreen protections to skip the warning.
- Download only the official releases from the repository and verify their
  origin.
- The repository is private: downloading from Releases requires a GitHub account
  with access. The public reachability of the updater endpoint (`latest.json`)
  is not verified and it is not public yet; never embed a personal token.
- Settings preservation during the native installer still needs a Windows check.
- Applying "Start with Windows" through Settings' manual Save remains pending
  (#19) and is out of scope for this version.

### Install
1. Open Releases on GitHub with an account that has access to the repository.
2. Download the `-setup.exe` installer (recommended) or the `.msi`.
3. Close Quorb from the tray menu using "Exit" («Salir»).
4. Back up `%APPDATA%\es.egdev.quorb` before replacing the current version.
5. Install and open Quorb.
