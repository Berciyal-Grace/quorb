# Quorb 0.3.1 — Añadir otra cuenta, paso a paso / Add another account, step by step

## Español

Una guía más clara para conectar cuentas adicionales de Claude, Codex y Gemini,
sin adelantar el login al guardado de la cuenta.

### Mejorado

- Ajustes guía la conexión: ponle nombre a la cuenta, inicia sesión con ella y
  comprueba si el CLI ha dejado su fichero de credenciales.
- **Guardar e iniciar sesión** guarda la configuración necesaria antes de abrir
  el login. La carpeta personalizada queda en **Avanzado · carpeta de sesión**.
- **Fichero de sesión encontrado** informa solo de su presencia: no confirma
  que el acceso sea válido. Comprueba el estado de la cuenta en el widget.

### Corregido

- Si falla el guardado, no se intenta abrir el login de una cuenta sin persistir
  ni se sustituye el error original por otro de login.
- El botón de conexión se deshabilita durante el guardado de Ajustes. Un guardado
  en curso no se trata como confirmación de que la cuenta ya esté guardada.
- Un fallo independiente de **Arrancar con Windows** no impide abrir el login
  cuando la configuración de la cuenta sí quedó guardada.

### Importante e instalación

- La validación real en Windows, el login del CLI y el aislamiento de cuentas
  siguen pendientes. Las carpetas son independientes por defecto; si eliges una
  ruta personalizada, comprueba que no sea la de tu cuenta principal.
- Esta versión no corrige la desaparición ocasional del widget ni acredita
  mejoras de accesibilidad.
- Cuando se publique, descarga el instalador Windows x64 EXE o MSI desde la
  release. No se prometen actualizaciones automáticas desde el repositorio privado.
- La firma del updater no es Authenticode ni evita los avisos de SmartScreen.
  No desactives las protecciones de Windows.

## English

A clearer guide to connect additional Claude, Codex and Gemini accounts,
without starting login before the account configuration is saved.

### Improved

- Settings walks you through naming the account, signing in with it and checking
  whether the CLI has written its credential file.
- **Save and sign in** saves the required configuration before opening login.
  A custom folder is available under **Advanced · session folder**.
- **Session file found** reports presence only, not valid authentication.
  Check the account status in the widget.

### Fixed

- A failed save no longer attempts login for an account that has not been
  persisted or replaces the original save error with a login error.
- The connection button is disabled while Settings is saving. An in-progress
  save is not treated as confirmation that the account has been saved.
- An independent **Start with Windows** failure does not block login when the
  account configuration was successfully saved.

### Important and installation

- Real Windows validation, CLI login and account isolation remain pending.
  Folders are separate by default; check that a custom path does not point to
  your primary account's folder.
- This release does not fix the occasional disappearing widget or establish
  accessibility improvements.
- Once published, download the Windows x64 EXE or MSI installer from the release.
  Automatic updates from the private repository are not promised.
- Updater signing is not Authenticode and does not prevent SmartScreen warnings.
  Do not disable Windows protections.
