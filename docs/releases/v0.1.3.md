# Quorb 0.1.3

Guardado manual más seguro para «Arrancar con Windows» (#19) y una renovación
visual de Ajustes (#30): tarjetas de módulo tipo «Grafito», navegación plegable,
configuración por proveedor en panel lateral y zoom inicial al 85 %.

## Español

### Lo que notarás
- «Arrancar con Windows» (#19): marcar o desmarcar la casilla ya no cambia nada
  al vuelo; deja el cambio como pendiente para que «Guardar cambios» se active.
  Si vuelves al valor confirmado, se limpia solo el cambio pendiente de
  arranque; el botón «Guardar cambios» vuelve a su estado normal solo si no
  queda ningún otro cambio manual pendiente.
- Si la lectura del estado de arranque falla, ves un aviso visible con
  «Reintentar»; la casilla no inventa un valor.
- El guardado informa por partes: si algo falla, dice qué se guardó y qué no,
  y puedes reintentar. No aparece un «Guardado ✓» conjunto falso.
- Las ediciones hechas mientras el guardado está en curso no se pierden y los
  guardados manuales solapados se evitan.
- Ajustes tiene un aspecto nuevo con tarjetas de módulo «Grafito», cabeceras de
  sección y controles más compactos.
- La navegación lateral se puede contraer y expandir para dejar más espacio al
  contenido.
- La configuración de cada proveedor se abre en un panel lateral, en lugar de
  alargar la página.
- La ventana de Ajustes se abre al 85 % de zoom, así que cabe más contenido sin
  cambiar el tamaño de la ventana.

### Importante
- Verificado en Linux (tests, comprobación de tipos dentro del build y
  `cargo test`). La validación visual y de instalación en Windows sigue
  **pendiente**; el arranque automático no se ha validado en Windows nativo.
- Teclado y lectores de pantalla: el foco de los modales y paneles laterales
  necesita ajustarse y validarse, y los anuncios para lectores de pantalla
  siguen pendientes de revisión. En esta versión no se reclama una mejora de
  accesibilidad.
- La desaparición ocasional del widget sigue en investigación y no está
  corregida en esta versión.
- El guardado no es atómico: se aplica por partes con confirmación. Si el cambio
  nativo se aplica pero la lectura de confirmación falla, se marca como no
  confirmado.
- Este instalador sigue sin firma Authenticode, así que Windows puede mostrar
  «Editor desconocido» o SmartScreen. La firma del updater (minisign) es
  distinta y no acredita al editor. No desactives las protecciones.
- El feed anónimo del updater sigue siendo privado e inaccesible (404 conocido).
  Mientras siga así, la actualización automática no funcionará: requiere un
  repositorio público o un canal de actualizaciones accesible.
- El repositorio es privado: descargar desde Releases exige una cuenta de GitHub
  con acceso. Nunca incrustes un token personal.
- No se promete actualización automática.

### Instalar
1. Abre Releases en GitHub con una cuenta con acceso al repositorio.
2. Descarga el instalador `-setup.exe` (recomendado) o el `.msi`.
3. Cierra Quorb desde el menú de la bandeja con «Salir».
4. Haz una copia de `%APPDATA%\es.egdev.quorb` antes de sustituir la versión.
5. Instala y abre Quorb.

## English

### What you'll notice
- "Start with Windows" (#19): ticking or unticking the box no longer changes
  anything on the spot; it marks the change as pending so "Save changes"
  becomes active. If you return to the confirmed value, only the autostart
  pending change clears; "Save changes" goes back to its normal state only when
  no other changes are pending.
- If reading the autostart state fails, you see a visible notice with "Retry";
  the box does not invent a value.
- Saving reports per part: if something fails, it says what was saved and what
  was not, and you can retry. A false combined "Saved ✓" does not appear.
- Edits made while saving is in flight are not dropped, and overlapping manual
  saves are avoided.
- Settings has a new look with "Grafito" module cards, section headers and more
  compact controls.
- The side navigation can be collapsed and expanded to give the content more
  room.
- Each provider's configuration opens in a side panel instead of lengthening
  the page.
- The Settings window opens at 85% zoom, so more content fits without resizing
  the window.

### Important
- Verified on Linux (tests, type checking inside the build and `cargo test`).
  Windows visual and installer validation remain **pending**; autostart has not
  been validated on native Windows.
- Keyboard and screen readers: focus in modals and side panels still needs
  adjustment and validation, and screen-reader announcements still need review.
  This version does not claim an accessibility improvement.
- The occasional widget disappearance is still under investigation and is not
  fixed in this version.
- Saving is not atomic: it applies per part with confirmation. If the native
  change applies but the read-back fails, it is marked as unconfirmed.
- This installer still has no Authenticode signature, so Windows may show
  "Unknown publisher" or SmartScreen. The updater signature (minisign) is
  different and does not vouch for the publisher. Do not disable protections.
- The anonymous updater feed is still private and inaccessible (known 404).
  While it stays that way, automatic updates will not work: it needs a public
  repository or an accessible update feed.
- The repository is private: downloading from Releases requires a signed-in
  GitHub account with access. Never embed a personal token.
- No automatic updates are promised.

### Install
1. Open Releases on GitHub with an account that has access to the repository.
2. Download the `-setup.exe` installer (recommended) or the `.msi`.
3. Close Quorb from the tray menu using "Exit" («Salir»).
4. Back up `%APPDATA%\es.egdev.quorb` before replacing the current version.
5. Install and open Quorb.
