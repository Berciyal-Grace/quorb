# Quorb 0.3.0

Varias cuentas por proveedor (#33/#34) y renovación de sesión asistida desde el widget (#40), más
correcciones. Reúne los cambios integrados desde la última versión publicada v0.1.3.

## Español

### Lo que notarás
- Cada proveedor admite varias cuentas a la vez (Claude, ChatGPT/Codex, Gemini, Cursor, GitHub
  Copilot, NaN Builders, OpenRouter, Anthropic API y OpenAI API). Pones nombre a cada cuenta
  adicional y tiene su propio círculo numerado, resumen y aviso.
- Claude, Codex y Gemini usan su propia carpeta de sesión por cuenta (`CLAUDE_CONFIG_DIR`,
  `CODEX_HOME` y `GEMINI_CLI_HOME`), así «Iniciar sesión» no pisa la principal; cada cuenta guarda
  sus claves por separado.
- El widget solo guarda sus ajustes: nunca borra cuentas, atajos ni secretos. Guardar la clave antes
  de crear la cuenta ya no la deja en «Falta conectar», y «Uso oficial» funciona también en cuentas
  adicionales.
- «Renovar sesión»: cuando hay datos de uso previos y la sesión caduca, se conservan atenuados y el
  botón cambia a «Renovar sesión». Abre el CLI oficial para volver a iniciar sesión; cuando guarda
  nuevas credenciales, Quorb detecta el cambio y vuelve a consultar.
- El widget vigila los ficheros de sesión de Claude Code, Codex y Gemini y recarga al detectar un
  cambio: mira cada ~15 s y, si hay una recarga en curso, reintenta en la siguiente comprobación.
  Recibes un aviso del sistema al perder una sesión si el interruptor maestro y los avisos nativos
  están activos. Codex usa `~/.codex/auth.json` como respaldo si `CODEX_HOME` no lo tiene.
- Ajustes: los proveedores son tarjetas pulsables y la ventana inicial es más alta, ajustada al monitor.

### Importante
- Verificado en Linux (tests, comprobación de tipos en el build y `cargo test`). La validación en
  Windows **sigue pendiente**: el alta de cuentas de extremo a extremo, el Administrador de
  credenciales y el login por CLI (sobre todo `GEMINI_CLI_HOME` en Gemini) están revisados y
  cubiertos con pruebas, pero no con una ejecución completa. No se reclama que funcione en Windows
  sin verificar.
- La recarga tras renovar no es instantánea: es sondeo (~15 s) y reintento en la siguiente
  comprobación si ya hay una recarga en curso.
- Al eliminar una cuenta se intenta borrar sus claves del Administrador de credenciales, pero si el
  gestor falla el error se ignora: no hay borrado garantizado.
- El foco de modales y paneles laterales y los anuncios para lectores de pantalla siguen pendientes:
  no se reclama mejora de accesibilidad. La desaparición ocasional del widget sigue en investigación
  y no está corregida.
- Este instalador sigue sin firma Authenticode, así que Windows puede mostrar «Editor desconocido» o
  SmartScreen. La firma del updater (minisign) es distinta y no acredita al editor. No desactives las
  protecciones.
- El feed anónimo del updater sigue privado e inaccesible (404 conocido): mientras siga así no se
  promete actualización automática. El repositorio es privado: descargar desde Releases exige una
  cuenta de GitHub con acceso. Nunca incrustes un token ni una clave personal.

### Instalar
1. Abre Releases en GitHub con una cuenta con acceso al repositorio.
2. Descarga el instalador `-setup.exe` (recomendado) o el `.msi`.
3. Cierra Quorb desde el menú de la bandeja con «Salir».
4. Haz una copia de `%APPDATA%\es.egdev.quorb` antes de sustituir la versión.
5. Instala y abre Quorb.

## English

### What you'll notice
- Each provider supports multiple accounts at once (Claude, ChatGPT/Codex, Gemini, Cursor, GitHub
  Copilot, NaN Builders, OpenRouter, Anthropic API and OpenAI API). You name each extra account and
  it has its own numbered ring, summary and alert.
- Claude, Codex and Gemini use their own session folder per account (`CLAUDE_CONFIG_DIR`, `CODEX_HOME`
  and `GEMINI_CLI_HOME`), so "Sign in" does not overwrite the main one; each account stores its own
  keys separately.
- The widget only saves its settings: it never erases accounts, shortcuts or secrets. Saving a key
  before creating the account no longer leaves it stuck on "Not connected", and "Official usage" also
  works on extra accounts.
- "Renew session": when there is previous usage data and the session expires, it is kept dimmed and
  the button changes to "Renew session". It opens the official CLI to sign in again; when it stores
  new credentials, Quorb detects the change and queries again.
- The widget watches the session files of Claude Code, Codex and Gemini and reloads when it detects a
  change: it checks every ~15 s and, if a reload is in flight, retries on the next check. You get a
  system notification when a session is lost if the master switch and native alerts are on. Codex
  falls back to `~/.codex/auth.json` when `CODEX_HOME` lacks it.
- Settings: providers are clickable cards and the initial window is taller, fitted to the monitor.

### Important
- Verified on Linux (tests, type checking inside the build and `cargo test`). Windows validation
  **remains pending**: end-to-end account onboarding, Credential Manager and CLI login (especially
  `GEMINI_CLI_HOME` for Gemini) are reviewed and covered by tests, but not by a full run. This version
  does not claim it works on Windows unverified.
- Reloading after renewing is not instant: it is polling (~15 s) and a retry on the next check if a
  reload is already in flight.
- Deleting an account tries to clear its keys from Credential Manager, but if the credential store
  fails the error is ignored: deletion is not guaranteed.
- Focus in modals and side panels and screen-reader announcements still need review: no accessibility
  improvement is claimed. The occasional widget disappearance is still under investigation and is not
  fixed.
- This installer still has no Authenticode signature, so Windows may show "Unknown publisher" or
  SmartScreen. The updater signature (minisign) is different and does not vouch for the publisher. Do
  not disable protections.
- The anonymous updater feed is still private and inaccessible (known 404), so no automatic updates
  are promised. The repository is private: downloading from Releases requires a signed-in GitHub
  account with access. Never embed a token or a personal key.

### Install
1. Open Releases on GitHub with an account that has access to the repository.
2. Download the `-setup.exe` installer (recommended) or the `.msi`.
3. Close Quorb from the tray menu using "Exit" («Salir»).
4. Back up `%APPDATA%\es.egdev.quorb` before replacing the current version.
5. Install and open Quorb.
