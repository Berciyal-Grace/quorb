# Quorb 0.1.1

Primera release en GitHub. Si ya usabas la 0.1.0 local, esta versión reúne las
mejoras de interfaz, ajustes y arranque ya fusionadas.

## Español

### Lo que notarás
- Ajustes más claros: el tamaño y el color se guardan solos, así que el botón
  «Guardar cambios» queda para los cambios manuales (avisos, orden y similares).
- Al guardar, ya no se pierden las ediciones hechas mientras el guardado estaba
  en curso.
- El arranque añade reintentos para cargar la configuración y los consumos,
  una posición inicial y estados visibles de «Cargando…» y «Reintentar».
- Nueva imagen de marca e ilustraciones en el repositorio.

### Importante
- Verificado en Linux (tests, typecheck y `cargo test`). La validación visual y
  de instalación en Windows siguen **pendientes**.
- No se afirma que el icono antiguo de la barra de tareas quede resuelto:
  requiere reconstruir, reinstalar y comprobar en Windows.
- El repositorio es privado: descargar desde Releases exige una cuenta de GitHub
  con acceso. El endpoint del updater (`latest.json`) aún no es público; nunca
  incrustes un token personal en la app.
- Se publica sin firma Authenticode. El instalador puede pedir confirmación del sistema.

### Instalar
1. Abre Releases en GitHub con una cuenta con acceso al repositorio.
2. Descarga el instalador `-setup.exe` (recomendado) o el `.msi`.
3. Cierra Quorb antes de instalar. Si usabas la 0.1.0 local, haz una copia de
   `%APPDATA%\es.egdev.quorb` antes de sustituirla; la conservación de ajustes
   durante la instalación aún debe comprobarse en Windows.

## English

### What you'll notice
- Clearer Settings: size and color save on their own, so the Save button is now
  for manual changes (alerts, order and similar).
- Saving no longer drops edits made while the save was in flight.
- Startup adds retries for configuration and usage loading, initial positioning,
  and visible "Loading…" and "Retry" states.
- New brand image and repository illustrations.

### Important
- Verified on Linux (tests, typecheck and `cargo test`). Windows visual and
  installer validation are still **pending**.
- No claim that the old taskbar icon is fixed: that needs a rebuild, reinstall
  and a Windows check.
- The repository is private: downloading from Releases requires a signed-in
  GitHub account with access. The updater endpoint (`latest.json`) is not public
  yet; never embed a personal token in the app.
- Published without Authenticode signing. The installer may ask for system confirmation.

### Install
1. Open Releases on GitHub with an account that has access to the repository.
2. Download the `-setup.exe` installer (recommended) or the `.msi`.
3. Close Quorb before installing. If you used local 0.1.0, back up
   `%APPDATA%\es.egdev.quorb` before replacing it; settings preservation during
   installation still needs verification on Windows.
